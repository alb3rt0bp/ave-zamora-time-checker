# ave-zamora-time-checker
Aplicación integral de comprobación de los tiempos de paso de los trenes en la estación de zamora

URL consulta trenes en tiempo real MD-LD: https://tiempo-real.largorecorrido.renfe.com/renfe-visor/flotaLD.json
URL consulta trenes con la secuencia de estaciones y la hora de paso planificada: https://tiempo-real.largorecorrido.renfe.com/renfe-visor/trenesConEstacionesLD.json
